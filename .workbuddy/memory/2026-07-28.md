## ⚠️ 重要环境发现：本无头 shell 无法 git push
- `git push` 在本 WorkBuddy Bash（无头/非交互）会卡死：仓库的 `credential.helper=helper-selector` 会弹 GUI 选凭据，无头环境弹不出来 → 永久挂起。
- 验证：设 `GIT_TERMINAL_PROMPT=0` + 清空 helper → 立即报 `could not read Username`（确认是鉴权问题，不是网络）。
- `manager` / `manager-core` 也都会挂（无缓存 token 可在此环境使用）。
- 结论：能成功 push 的地方是**助理面板（可弹 GUI 的会话）**——昨天 Q75 就只在那里 push 成功。
- 后续做法：本 shell 只负责 `git commit`；`git push` 让用户从助理面板执行，或用户给 GitHub PAT 后我配置无头凭据（如 `credential.helper '!f() { echo username=...; echo password=$PAT; }; f'`）再 push。本次 448a467 仅本地提交，未推送。
